# LLM Atlas · 大模型学习系统（课程制）

一个每天自动运转的 AI 学习小组，目标是**帮基础较弱的工程师把大模型地基打牢**。

不再追新闻。总策划、讲师、助教、主编四个角色每天按固定课程路径备一课、审一课、成稿一课，笔记全部用 **Obsidian 库**承载：双链、关系图谱、术语卡、课程地图自动长出来。

---

## 一、学习路径：推理优先，昇腾 + vLLM 主栈

共 34 个模块 / 约 41 天（每天一课，每 4 课一次串讲复习）。顺序经过刻意设计：

| 阶段 | 模块（节选） | 目的 |
| --- | --- | --- |
| 🧱 地基（3 天） | 前向传播与梯度下降 → 反向传播与优化器 → Transformer 基础 | 没有这个，后面全是空中楼阁 |
| ⚙️ 推理主线（约 9 天） | 推理服务基础 → vLLM 引擎 → **昇腾 NPU 架构** → **昇腾上的 vLLM** → 量化编译 → 投机解码 → PD 分离 → 推理成本 | 先学透一个 token 的推理链路，用的就是你工作的栈 |
| 🔥 训练（约 11 天） | 预训练与 scaling law → 分布式并行 → 后训练 → 数据工程 → MoE → 评估 → 训练基础设施 | 再回头学能力从何而来 |
| 🚀 拓展（约 18 天） | SGLang / TensorRT-LLM / llama.cpp；NVIDIA GPU / HBM / 互联；推理模型 / 长上下文 / 多模态 / Agent | 在主栈地基上向其他框架与硬件延伸 |

完整路径见 [`config/agents.json`](config/agents.json) 的 `learning_path`，可视化看 [`课程地图.md`](课程地图.md) 或看板的「知识地图」。

## 二、每天怎么运转

```
每天 08:30（Asia/Shanghai）
        │
        ▼
┌──────────────┐   按 learning_path 选下一个未学模块
│ 总策划 Planner │   （多天模块自动续课；每 4 课切换到串讲日）
└──────┬───────┘
       ▼
┌──────────────┐   只用稳定材料：官方文档、经典论文、教材
│  讲师 Teacher  │   每个术语从零解释；带数字的 worked example
└──────┬───────┘
       ▼
┌──────────────┐   概念对错 / 初学者友好度 / 有没有偷用没学过的知识
│  助教 Auditor  │
└──────┬───────┘
       ▼
┌──────────────┐   成稿：课前自测 → 核心概念 → 逐步推导 → 误区 → 自测题
│  主编 Editor   │   → 术语卡 → 下一步
└──────┬───────┘
       ▼
┌──────────────┐   落盘 课程/<领域>/<日期>-<模块>.md，重建索引
│  归档 Archiver │   术语库 / 课程地图 / 看板自动更新
└──────────────┘
```

- **每 4 课一次串讲复习**：把四课串成一张图 + 综合自测 + 易混淆对照表；
- **每周一份「动态简报」**（周一）：3–5 条行业动态，存在 `动态/` 里，**与课程完全分开**，想看才看；
- **专题（按需）**：想深入某个主题（比如 Mamba 家族），随时说一句，专题工作流会从模型演进 / 推理框架 / 硬件三个视角并行出三篇笔记，存在 `专题/` 里，同样走「研究员 → 助教 → 主编」流程；
- 每个模块 1–2 天，学不完就续课，**宁可慢而透**。

## 三、用 Obsidian 承载

整个 `Learning` 文件夹就是一个 Obsidian 库（vault）。

**打开方式**：Obsidian →「打开其他仓库」→「打开本地仓库」→ 选择 `~/Desktop/Learning`。

开箱即用：

| 文件 | 作用 |
| --- | --- |
| [`首页.md`](首页.md) | 总入口：今天学什么、进度、最近课程 |
| [`课程地图.md`](课程地图.md) | 34 个模块的学习路径与完成状态 |
| [`知识地图.canvas`](知识地图.canvas) | 白板视图，核心笔记一张图 |
| [`术语库.md`](术语库.md) | 全部课程术语自动聚合，按领域分组，可当复习卡片刷 |
| [`动态索引.md`](动态索引.md) | 每周动态简报的索引 |
| `课程/<领域>/` | 每日课程笔记（带 frontmatter 与双链） |
| `knowledge/` | 各领域 MOC（模块进度 + 学习记录） |

特性：

- **关系图谱**：点左侧「关系图谱」，五个领域按颜色分组，课程越学越多，图谱自动长出来（颜色在 `.obsidian/graph.json`）；
- **双链**：每篇笔记通过 `[[…]]` 连到领域 MOC、上一课、术语库；鼠标悬停预览；
- **标签**：笔记 frontmatter 的 tags 会出现在标签面板；
- **模板**：`templates/课程模板.md` 可用于手动补记（一般用不到，工作流会自动写）。

> 可选：安装社区插件 **Dataview**，`日报索引` 类页面可换成自动查询（当前静态表已够用）。
> 建议把 `Learning` 文件夹放进 iCloud/坚果云同步，手机 Obsidian 也能看。

网页看板 [`dashboard/index.html`](dashboard/index.html) 保留：单文件、离线可开，适合快速浏览与移动端分享；它与 Obsidian 读的是同一批 Markdown。

## 五、每天怎么跑

### 自动（推荐）

每天 **08:30** 定时提醒触发，编排 Agent 按 [`scripts/daily-playbook.md`](scripts/daily-playbook.md) 执行：读取进度 → 调 `workflow-course.js`（自动判断今天该上课 / 串讲 / 动态简报）→ 归档落盘 → 重建索引。

> 需要 DSH 会话在线。错过就说「补跑今天的课」，或「补第 N 课」。

### 手动

- 「跑今天的大模型学习课程」→ 按路径上一课；
- 「跑一次串讲复习」→ 手动触发串讲；
- 「出一份本周动态简报」→ 手动触发动态简报；
- 「帮我整理 XX 专题」→ 三视角并行出专题笔记（模型演进 / 推理框架 / 硬件）；
- 「批量生成第 N–M 课」→ 用 `scripts/workflow-batch.js` 一次生成一批课（每门课仍走 讲师→助教→主编→归档 完整流水线，并行执行，质量与单课一致），批次结束后统一重建索引；
- 「重学 / 跳过模块 X」→ 我改 coverage 状态后重新排课。

## 六、质量红线

- **不追新闻**：课程正文只用稳定来源（官方文档、经典论文、教材）；新闻只进 `动态/`；
- 每个术语第一次出现必须解释；不偷用没学过的知识；
- 带数字的 worked example 必须能跟着手算；助教会重算核对；
- 不确定就写「存疑」，绝不编造公式、数字、URL；
- 每课都有自测题（答案藏在 `<details>` 里），先做再看答案。

## 八点五、手机划词提问

看板支持在手机上**选中文章内容 → 「＋ 标记疑问」→ 写下问题**，存在本机浏览器；在「我的疑问」里可复制 / 下载 / 分享。
把导出的 `.md` 放进 [`疑问/`](疑问/README.md)，然后对我说「看我的疑问」，我会逐条讲解并指出理解偏差。
