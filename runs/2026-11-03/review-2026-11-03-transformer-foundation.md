## 问题清单（issues）

### 1. [medium]

- **claim**：怎么读结果：「我」的输出 76.8% 来自自己；「昇腾」对谁都贡献 1/3，于是它的输出是三个向量的平均。
- **problem**：注意力权重矩阵要按行读：第 i 行是第 i 个 token 的 query 分给各 key 的权重。「昇腾对谁都贡献 1/3」说的是列语义（昇腾给别人贡献多少），而第 3 列实际是 [0.187, 0.187, 0.333]，并不均匀；均匀的是第 3 行（昇腾从每个 token 各取 1/3）。行列说混恰好落在初学者最容易出错的地方，会种下错误直觉。
- **fix**：改为「『昇腾』这一行的注意力权重对三个 token 都是 1/3——它从每个位置等量地取信息，所以它的输出是三个 V 的平均」；顺手加一句「行 = 我这个 query 把注意力分给谁，列 = 每个 key 被多少个 query 读取」帮助读者建立行/列对应。

### 2. [medium]

- **claim**：（decoder 里还会加因果 mask——把「未来」token 的分数置为负无穷再 softmax，使权重为 0；下集讲 decoder-only 时展开。）
- **problem**：decoder 是全篇第一次出现且没有任何定义或铺垫；目标读者是基础较弱的工程师，刚学完 RNN/attention，不知道 decoder 指什么——而本模块的主题恰恰是 decoder-only，这个词不能悬空到下一集。
- **fix**：补一句最小定义，如「（在只按从左到右逐字生成的 decoder（解码器）模型中，还要加因果 mask……；decoder 与 decoder-only 是什么，下集展开）」，或在术语卡中先给 decoder 一条占位解释。

### 3. [low]

- **claim**：- 长距离：第 1 个词的信息传到第 1000 个词要经过 999 次「压缩—传递」，容易丢；训练时还伴随梯度消失。
- **problem**：「梯度消失」未解释就使用；课前自测确认过的基础只有损失函数与梯度下降，梯度消失不在其列，弱基础读者会卡住。
- **fix**：补半句白话：「梯度消失（反向传播时靠前位置几乎收不到梯度信号，参数学不动）」；或删去此半句，把梯度问题留给训练相关章节。

### 4. [low]

- **claim**：## 下一步 …位置信息从哪来（RoPE）、归一化怎么做省（RMSNorm）、前馈层用什么激活（SwiGLU），并解释 GQA 与「为什么主流都做 decoder-only」。
- **problem**：RoPE/RMSNorm/SwiGLU/GQA 四个缩写在本课零解释地出现；弱基础读者在「下一步」就卡壳，而这些正是模块目标 3 要考察的名词。
- **fix**：首次出现时给出全称：旋转位置编码（RoPE）、均方根归一化（RMSNorm）、SwiGLU 激活函数、分组查询注意力（GQA），并注明下集展开。

### 5. [low]

- **claim**：本课整体结构（无模块目标映射标注）。
- **problem**：模块目标 3、4（RoPE/RMSNorm/SwiGLU/GQA、为什么主流是 decoder-only）全部落在下集，本集只覆盖目标 1、2；讲义没有显式标出「本集对应哪几条目标」，学生无法对号入座确认覆盖与缺口。
- **fix**：在课前自测开头或「下一步」处加一行目标映射，如「本集覆盖模块目标 1–2（attention 在做什么 / 公式逐项）；目标 3–4 由下集覆盖」。

### 6. [low]

- **claim**：定义：把 Q、K、V 各切成 h 份，每份 d_model/h 维，独立做 scaled dot-product attention，h 个输出拼接后经 W^O 投影。
- **problem**：与紧接的公式（每头分别乘 W_i^Q/W_i^K/W_i^V）表述不一致：论文做法是每头用自己的一套投影矩阵投到 d_k = d_v = d_model/h，「切成 h 份」只是等价简化的说法；直接说「切」容易让初学者误以为多头是无参数的切片操作。
- **fix**：改为「每头用一套小投影矩阵把 Q/K/V 投成 d_model/h 维再独立做 attention（等价于把一个大头切成 h 个小头）」，与公式对齐。
