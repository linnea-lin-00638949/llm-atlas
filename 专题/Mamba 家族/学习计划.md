## Day 1 · SSM 的三种算法：递推、离散化、卷积

**目标**：能手算 4 步标量 SSM 递推；能说出 Ā、B̄ 的物理含义；知道「卷积视图」是并行的基础。

- 读：模型演进「核心概念」的 SSM、状态维度 N、离散化、HiPPO、卷积视图。
- 手算：
  1. a = −1、Δ = 0.1，算 Ā、B̄（精确式），再算近似式 Δb，比较差多少。
  2. x = [1, 0.5, −0.2, 0.8]，从 h₀ = 0 递推 4 步，写出每个 h_t。
  3. 用矩阵 M 的 t、s 通项解释：为什么 y_t 只依赖 x_s（s ≤ t）。
- 实验：`lab_ssm.py` 实验 1（递推 = 卷积矩阵 = 并行 scan）。
- 自测：模型演进自测题 1–2。
- **完成标准**：能解释「B̄ ≈ ΔB 只在 |Δa| ≪ 1 时成立」，并能算出 Δa = −0.1 时 5% 的偏差。

## Day 3 · Mamba-2 与 SSD：从 scan 到大矩阵乘

## 附录 A · 公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| SSM 递推 | h_t = Ā h_{t−1} + B̄ x_t，y_t = C h_t | 每步 O(1) 状态读写 |
| 离散化（ZOH） | Ā = e^{Δa}，B̄ = (e^{Δa}−1)/a·b | 近似 B̄ ≈ Δb 仅当 \|Δa\| ≪ 1 |
| 卷积视图 | y_t = Σ_{s≤t} C(∏ Ā) B̄ x_s | 核固定时可 FFT |
| scan 复合 | (a₂,b₂)∘(a₁,b₁) = (a₂a₁, a₂b₁+b₂) | 结合律 → 树形并行 |
| chunked 复杂度 | O(n(L+N)D) | 块内 GEMM，块间串行 n/L 次 |
| chunk 算术强度 | AI ≈ (L+D)/2 | 口径：只算 q/k/v/o 四个张量 |
| KV/token | 2 · 层数 · KV头数 · head_dim · 2B | Llama-3-8B = 128 KiB |
| 状态/序列 | 层数 · heads · head_dim · d_state · 2B | 与上下文长度无关 |

## 附录 B · 五个最容易踩的坑

1. **把状态当「压缩版 KV」**：状态不可寻址、只进不出、与长度无关；KV 可随机访问、随长度增长。语义不同，不能互换。
2. **B̄ ≈ ΔB 无条件用**：只在 |Δa| ≪ 1 成立；Δa = −0.1 时已差 5%。
3. **块间串行次数写成 L**：串行的是块数 n/L，不是块长 L。
4. **「省显存」= 一定更快**：短上下文时状态比 KV 贵；decode 是否更快取决于算术强度与带宽。
5. **混合模型只看比例**：Jamba 省 8 倍是因为 attention 只占 4/32 层，不是 Mamba 单层的魔法。
