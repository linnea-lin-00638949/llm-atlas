# 第 1 轮串讲 · 2026-11-03

> 本轮四课：第 1 课 · 神经网络在算什么、第 2 课 · 反向传播与优化器、第 3 课 · Transformer 与 decoder-only 范式（上）、第 4 课 · Transformer 与 decoder-only 范式（下）

## 一张图串起来

前两课讲「怎么学」，后两课讲「学的是什么结构」，接起来是一条闭环：

```
token → embedding → ┌ 一层 decoder（重复 N 次）─────────────────┐
                    │ 归一化 → 因果注意力(Q,K,V + RoPE) → 残差    │
                    │        → 归一化 → SwiGLU 前馈      → 残差    │
                    └───────────────────────────────────────────┘
                    → 输出头 → softmax → 下一个 token 的概率
                    → 交叉熵 → 损失 L          【第 1 课：量差距】
                    → 链式法则反向            【第 2 课：算梯度】
                    → SGD / Momentum / Adam   【第 2 课：改参数】
                    → 新的 W_Q、W_K、W_V、γ、W_gate… ┘ 回到最左边
```

依赖是逐层加码的：

- **第 1 课**给出最小闭环「算—量—改」，并定义了后面所有零件：线性层 `z=Wx+b`、ReLU、softmax、梯度、学习率。
- **第 2 课**把「手算一个参数的偏导」升级成「一次反向算完全部梯度」，再补上优化器。第 1 课是单参数手工作坊，第 2 课是上亿参数流水线。
- **第 3 课**把抽象的「层」换成 Transformer 层：注意力用 `softmax(QKᵀ/√d_k)V` 一步重排全序列，多头给多个视角，残差让深层训得动——用的全是前两课的工具。
- **第 4 课**把骨架打磨成能训、能部署的形状：RoPE 补位置、RMSNorm 补稳定、SwiGLU 补表达、GQA 补成本，收敛到 decoder-only + KV cache。

一句话的因果链：**没有激活函数就退化成线性 → 要有非线性；有非线性才谈梯度 → 所以有反向传播；会反向才能训深 → 所以有残差；能训深才堆得出 Transformer；一上线成本成为新问题 → 所以有 GQA 与 KV cache。**

## 综合自测

### 1. 推理显存远小于训练显存，但推理又有个 KV cache 吃掉一大块——矛盾吗？

<details><summary>查看答案</summary>

不矛盾，是两类不同开销。训练除参数外还要存每层中间激活（前向缓存给反向用）、每个参数的梯度、以及优化器状态（Adam 的一阶矩 m 和二阶矩 v）——常是权重十几倍量级。推理权重只读、只做前向，没有激活缓存、梯度、优化器状态，多出来的是「不重算历史 K/V」的 KV cache。

所以：训练多出来的开销是为了**改参数**，KV cache 是为了**省重算**。后者随序列长与 batch 线性长，长上下文时会变成主项。

</details>

### 2. 设 `L=½(ŷ−y)²`、`ŷ=w·a`，当前 `ŷ=0.9`、`y=1`、`a>0`。`w` 该变大还是变小？学习率特别大会怎样？

<details><summary>查看答案</summary>

`∂L/∂ŷ = ŷ−y = −0.1`，`∂L/∂w = −0.1·a < 0`。梯度为负 = 增大 w 会让损失下降，所以 `w ← w − η·(负数)` 使 w **变大**，预测从 0.9 朝 1 靠。

学习率过大的后果见第 1 课的 `L(w)=w²`：一步跨过谷底落到对面更高处，在最优值两侧震荡；再大就发散，loss 剧烈抖动或直接 NaN。注意每步只沿当前点的局部最陡方向，不保证一步到位。

</details>

### 3. `√d_k` 缩放、学习率过大、softmax 饱和，是同一类问题吗？

<details><summary>查看答案</summary>

是同一类：都是「尺度没匹配」导致训练不稳，症状都从 loss 曲线上读。

- `√d_k`：q、k 各维独立且均值 0 方差 1 时，点积方差是 d_k。d_k 越大分数越极端，softmax 进饱和区（近 one-hot），该处梯度近 0、学不动。除以 `√d_k` 把方差拉回 1。
- 学习率过大：一阶近似 `L(θ−ηg) ≈ L(θ) − η‖g‖²` 只在步长小时成立，η 太大越过有效区间。

区别：`√d_k` 是写进架构的固定设计，η 是可调超参。病根相同——数值尺度失控。

</details>

### 4. 残差 `F(x)+x` 为什么让深层网络训得动？用链式法则写出来。

<details><summary>查看答案</summary>

设 `y = x + F(x)`，则 `∂y/∂x = 1 + ∂F/∂x`。反向时上游梯度乘这个因子往回传，关键就是常数 1：即使 `∂F/∂x` 接近 0，总梯度也不会被衰减成 0，能原样穿回浅层。对比 RNN 的隐藏状态连乘，每环都小于 1，乘几十上百次就消失。

额外保险：F 没学好（`F(x)=0`）时层输出仍等于输入，网络不会立刻崩。Transformer 每个子层都是「`F(x)+x` → 归一化」。

</details>

### 5. 一层 decoder 里的非线性来自哪几处？把激活都换成恒等会怎样？

<details><summary>查看答案</summary>

主要两处：注意力的 **softmax**（把任意实数分数变成非负、和为 1 的权重）和前馈层的 **Swish / ReLU**（`Swish(z)=z·σ(z)`）。RMSNorm 的除法严格说也非线性，但它的职责是压尺度，不承担表达力。

若全换成恒等：一层只剩矩阵乘与加法，复合后仍是线性变换，堆 100 层等于堆 1 层，深度失去意义。

补一句：SwiGLU 的逐元素乘 `⊙` 本身也带来非线性，所以门控结构不完全依赖 Swish；但少了 Swish 就丢掉负值区的小梯度，优化更差。

</details>

### 6. 配置：80 层、64 个 Q 头、8 组 KV、head_dim=128、fp16，序列 4096、batch=1。KV cache 多大？若用 64 组 KV 的 MHA 呢？

<details><summary>查看答案</summary>

公式：`2 × 层数 × n_kv_heads × head_dim × 序列长 × 字节数 × batch`。

代入 `2×80×8×128×4096×2×1` ≈ **1.3 GB**。换成 MHA（`n_kv_heads=64`，8 倍）≈ **10.7 GB**。

省下的 9 GB 多可换更大 batch 或更长上下文——这正是 GQA 的意义：Q 头数不变（表达不变），只把 KV 份数从 `n_heads` 降到 `g`，缓存缩到 `n_heads/g`。另注意 `num_key_value_heads` 由权重决定、写在配置里，运行时改不了，规划 NPU 显存要按它算。

</details>

### 7. decode 阶段为什么合并三个线性层为一次 GEMM、并尽量不让 (n,n) 分数矩阵写回显存？这与 KV cache 同一动机吗？

<details><summary>查看答案</summary>

同源但不相同，都围绕带宽。decode 每步只进 1 个新 token，算术量很小，却要把整个 KV cache 读一遍——访存受限，卡在带宽而非算力。合并 GEMM 减少 kernel 启动与重复访存；融合算子让分数矩阵不落地，少一次写回再读出。

KV cache 省的是**重算**（不缓存则每步重算历史 K/V，计算量随序列长平方增长），算子融合省的是**搬运**。两者都在回答：decode 的瓶颈是内存带宽，不是 FLOPs。

</details>

### 8. MSE 和交叉熵各适合什么？LLM 为什么用交叉熵？

<details><summary>查看答案</summary>

MSE 适合回归：输出连续值，平方让大误差被按平方放大（差 2 罚 4、差 10 罚 100），模型被迫优先消大误差。

交叉熵衡量两个概率分布的差距，适合分类——包括「在词表上分类」的下一个 token 预测：输出头映射到词表维度、softmax 成分布，再与真实 token 的 one-hot 算交叉熵。实操原因是梯度干净：对 logits 的梯度就是「预测概率 − 目标概率」，不会像「MSE + softmax」那样在饱和区梯度趋 0——这和第 3 题是同一件事的两种解法。

</details>

## 易混淆对照表

| 容易混的概念 | 区别一句话 |
| --- | --- |
| 前向传播 / 反向传播 | 前者算预测，后者算「每个参数该为误差负多少责」；推理只有前者 |
| 梯度 / 优化器 | 梯度是账本（往哪动、动多少的原始信息），优化器是行动方案（实际动多少） |
| 反向传播 / 参数更新 | 反向只把梯度累加进 `.grad`，参数值不变；真正改参数的是优化器那步 `θ←θ+Δθ` |
| 学习率 α / `√d_k` 缩放 | 都是尺度旋钮，但 α 可调，`√d_k` 是写进架构的固定设计 |
| 激活函数 / 归一化 | 激活提供非线性（深度才有意义），归一化只压尺度，不提供表达力 |
| 多头注意力 / GQA | 多头是「多个 Q 头各看一个子空间」（影响表达），GQA 是「多 Q 头共用 K/V」（影响显存） |
| Q 头数 / KV 头数 | Q 头数决定输出维度与表达，KV 头数决定 KV cache 大小 |
| RoPE / 绝对位置编码 | 前者旋转 Q、K 让分数只依赖相对距离 `m−n`，后者往 embedding 上「加」位置向量 |
| 残差 / 归一化 | 残差保「信息与梯度的直通路」，归一化保「尺度不失控」，互不替代 |
| 注意力里的 softmax / 输出层 softmax | 前者在「序列位置」上分配权重，后者在「整个词表」上给每个候选词概率 |
| 训练损失低 / 模型好 | 损失低只说明记住了训练数据；好不好看它在没参与训练的数据上的表现 |
| MSE / 交叉熵 | MSE 罚连续值偏差，交叉熵罚分布差距；LLM 用后者 |
