# 第 1 课 · 神经网络在算什么

> 学完今天，你能：

> 2. 说清损失函数到底在衡量什么
> 3. 解释梯度下降每一步在做什么，以及学习率过大/过小各有什么后果

## 课前自测

1. 一个三层（2 个隐藏层 + 1 个输出层，全课约定输入层不算层）、但没有任何激活函数的网络，能力上等价于什么？
2. 均方误差为零，说明模型在训练数据上表现如何？这能保证它在新数据上也一样好吗？
3. 梯度方向是损失上升最快的方向，那更新参数时为什么要「减去」梯度？学习率设得特别大会发生什么？

## 为什么需要它

你每天在昇腾 NPU（神经网络专用处理器）上用 vLLM（大模型推理引擎）跑的服务，本质是每秒做成千上万次前向传播：输入文本，逐层算出下一个词元（token，文本被切分出的最小单位）的概率。这一课把三件事说透：网络在算什么（前向传播）、预测离目标多远怎么量（损失函数）、参数靠什么改（梯度下降）。这是全课程第一块地基：下一课的反向传播，只是把「算梯度」这件事变得高效。

## 核心概念

### 感知机（神经元）

定义：一个神经元接收输入 x₁…xₙ，先加权求和、加偏置，再过激活函数：

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b
y = f(z)

w 叫权重（weight），b 叫偏置（bias），f 是激活函数。名称来自 1958 年 Rosenblatt 的工作，当时 f 是阶跃函数；今天的神经元沿用同一骨架，只是换了更实用的 f。

直觉：想象评委打分。每个输入是单项成绩，权重是这项的重要性，偏置是评委心里的基础分，z 是加权总分；激活函数决定总分如何变成最终信号。

机制：权重和偏置就是参数，是训练要改的对象。改权重 = 改变某项输入的话语权；改偏置 = 把激活的「分界线」整体平移。真实网络中上亿个神经元同时做这件事，被组织成矩阵乘法。

### 激活函数

定义：施加在加权和 z 上的函数 f。最常用的是 ReLU（Rectified Linear Unit，线性整流单元）：f(z) = max(0, z)，正数原样通过、负数置零。

直觉：线性变换（输出是输入的加权和，最多加个常数）在几何上包括拉伸、旋转、平移等，但直线永远是直线，分界线永远是直的。激活函数给计算加入「弯曲」，像把纸折一下，本来分不开的点就能分开了。

机制（为什么必须有）：先约定符号——ŷ（读作 y-hat）表示模型预测值，y 表示真实目标，戴帽子的都是模型算出来的量。两层不带激活函数的网络 ŷ = W₂(W₁x + b₁) + b₂，展开就是 (W₂W₁)x + (W₂b₁ + b₂)，仍是「加权求和 + 偏置」。线性变换复合线性变换还是线性变换，深度变得毫无意义。非线性能力全部来自激活函数。例如 XOR（异或）问题：四个点用一条直线分不开，但一层带 ReLU 的隐藏层可以。

### 损失函数

定义：把「预测与目标差多远」压缩成一个标量的函数 L(ŷ, y)。训练的目标就是不断调参数把 L 压低。

直觉：考试扣分。目标 y 是标准答案，预测 ŷ 是你的答案，损失是扣了多少分；扣分规则越严，模型越不敢犯大错。

机制：回归任务最常用 MSE（Mean Squared Error，均方误差）：

L = (1/n) Σ (ŷᵢ − yᵢ)²

平方带来两个好性质：大误差惩罚按平方放大（差 2 罚 4，差 10 罚 100），模型被逼着优先消除大误差；且 L ≥ 0，只有全部命中才等于 0。分类任务（含大语言模型预测下一个词）常用交叉熵（度量两个概率分布差多远），第 2、3 课讲。

### 梯度下降与学习率

定义：把 L 对每个参数求偏导（partial derivative，偏导 = 把其他参数当常数、只对其中一个参数求导数，衡量「只动这一个参数时损失怎么变」），所有偏导拼成的向量叫梯度 ∇L。梯度指向损失上升最快的方向；每步沿负梯度方向更新：

θ ← θ − η·∇L(θ)

η 叫学习率（learning rate），决定这一步迈多大。

直觉：蒙眼下山。只能摸到脚下地形的坡度（梯度），就往最陡的下坡方向挪一小步；挪完重新摸，再挪。每一步的方向只是当前位置的局部最陡下坡，不保证全局最优，但小步重复通常能走到谷底附近。

机制（为什么沿负梯度下降）：先用一维例子 L(w) = w²（梯度 2w），从 w = 1 出发：

- η = 0.1：w ← 1 − 0.2 = 0.8，慢慢逼近 0，安全但慢；
- η = 1：w ← 1 − 2 = −1，下一步又回 1，永远在 ±1 震荡，不收敛；
- η = 1.5：w ← 1 − 3 = −2，下一步跳到 4，越跳越远，发散。

> 进阶附注（可跳过）：为什么负梯度方向必然降损失？把 L 在当前位置做一阶近似（泰勒展开只留线性项，即用一条切线近似曲线）：L(θ − ηg) ≈ L(θ) − η‖g‖²，其中 ‖g‖² 是梯度这个向量的长度平方，恒 ≥ 0。只要 g ≠ 0 且 η 足够小，第二项恒正，损失必然变小；但一阶近似只在步长小时成立，η 太大就失真——这就是 η = 1.5 发散的原因。

## 一步一步理解

目标：手工算一个两层网络的前向传播加一步梯度更新。约定：输入层不算层（没有参数），「两层」= 1 个隐藏层 + 1 个输出层。

输入 x = (1, 2)，目标 y = 1，激活函数用 ReLU。

第一步，隐藏层两个神经元。
神经元 1（w = (0.4, −0.3)，b = 0.5）：z₁ = 0.4×1 + (−0.3)×2 + 0.5 = 0.3 → h₁ = max(0, 0.3) = 0.3
神经元 2（w = (0.8, 0.1)，b = −0.2）：z₂ = 0.8×1 + 0.1×2 + (−0.2) = 0.8 → h₂ = 0.8

第二步，输出层一个神经元（w = (0.7, −0.2)，b = 0.1）：ẑ = 0.7×0.3 + (−0.2)×0.8 + 0.1 = 0.15

第三步，算损失（MSE，单样本）：L = (0.15 − 1)² = 0.7225

第四步，更新一个权重。只看输出层第一个权重 w₀ = 0.7，用链式法则（复合函数求导的连乘规则，下一课细讲）：∂L/∂w₀ = 2(ẑ − y)·h₁ = 2×(−0.85)×0.3 = −0.51。梯度为负 → w₀ 应变大，预测朝 1 靠拢。取 η = 0.1：w₀ ← 0.7 − 0.1×(−0.51) = 0.751

第五步，验证损失变小：新预测 ẑ' = 0.751×0.3 − 0.16 + 0.1 = 0.1653，新损失约 0.697 < 0.7225。✓

两点注意：(1) 真实训练同时更新所有参数，这里只演示一个；(2) 参数上亿时不可能手算梯度——下一课的反向传播用链式法则一次算完。工程上推理只有前向传播、没有损失和梯度：这是推理显存远小于训练显存的原因之一（训练还要存每层中间输出、梯度和优化器状态）。

## 常见误区

误区一：「激活函数的作用是把输出压到 0–1」。纠正：压到 0–1 只是 sigmoid（S 形函数）这类函数的性质，ReLU 输出可以任意大。激活函数真正的作用是引入非线性，没有它网络退化成一层线性变换。

误区二：「没有激活函数，靠堆更多层也能拟合复杂函数」。纠正：多层线性变换复合后仍是线性变换，层数再多只是把同一件事重新编码一遍，表达能力没有增加。

误区三：「学习率越大收敛越快，越大越好」。纠正：学习率要和损失曲面的弯曲程度匹配。太大时一步跨过谷底落到对面更高处，表现是震荡甚至发散（w² 例子 η = 1 永远震荡）。工程上训练日志里 loss（损失）曲线剧烈抖动、或直接变成 NaN（Not a Number，非数），第一时间怀疑学习率过大。

误区四：「训练损失越低越好，压到接近零就成功了」。纠正：损失低只说明模型记住了训练数据；若是死记硬背而没学到规律，遇到新数据反而差，这叫过拟合（overfitting）。评估要看模型在没参与训练的数据上的表现，后面课程专门讲。

## 一句话总结

前向传播算预测，损失函数量差距，梯度下降改参数：「算—量—改」三件事闭环，就是神经网络学习的全部骨架。

## 自测题

### 1. 手工算前向传播
一个神经元，输入 x = (1, 2)，权重 w = (0.4, −0.3)，偏置 b = 0.5，激活函数 ReLU。算出加权和 z 与输出 h。
<details><summary>查看答案</summary>

z = 0.4×1 + (−0.3)×2 + 0.5 = 0.3；h = f(z) = max(0, 0.3) = 0.3（z > 0，正数原样通过）。

</details>

### 2. 损失函数在衡量什么
MSE 为零说明模型在训练数据上表现如何？能保证新数据也准吗？
<details><summary>查看答案</summary>

MSE = (1/n)Σ(ŷᵢ − yᵢ)² ≥ 0，等于零说明每个预测都和训练目标完全一致，训练误差为零。但不能保证新数据也准：模型可能只是死记硬背训练数据（过拟合），没学到规律，在新数据上反而差。所以评估要看模型在未参与训练的数据上的表现。

</details>

### 3. 学习率过大/过小
在 L(w) = w²（梯度 2w）、从 w = 1 出发的例子中，η = 0.1 / 1 / 1.5 各发生什么？各对应「过大」还是「过小」？
<details><summary>查看答案</summary>

η = 0.1（过小）：w ← 1 − 0.2 = 0.8，逐步逼近 0，安全但慢；η = 1（过大）：w ← 1 − 2 = −1，下一步又回 1，在 ±1 间永远震荡，不收敛；η = 1.5（过大）：w ← 1 − 3 = −2，下一步跳到 4，越跳越远，发散。学习率要和损失曲面的弯曲程度匹配：太大一步跨过谷底，太小进展太慢。

</details>

### 4. 无激活函数的网络
三层网络（2 个隐藏层 + 1 个输出层，输入层不算层）但没有任何激活函数，表达能力上等价于什么？
<details><summary>查看答案</summary>

等价于一层线性变换（加权求和 + 偏置）。线性变换复合线性变换还是线性变换：ŷ = W₂(W₁x + b₁) + b₂ 展开仍是「权重矩阵 × 输入 + 常数」，深度没有带来表达能力提升。非线性能力全部来自激活函数。

</details>

### 5. 为什么要「减」梯度
梯度指向损失上升最快的方向，为什么更新要「减」梯度？用本课手算例子的数字说明。
<details><summary>查看答案</summary>

减梯度 = 沿最陡的下坡方向走。手算例子里 ∂L/∂w₀ = 2(ẑ − y)·h₁ = 2×(−0.85)×0.3 = −0.51 为负，说明 w₀ 增大时损失下降，所以更新要往反方向（增大 w₀）走：w₀ ← 0.7 − 0.1×(−0.51) = 0.751。新预测 ẑ' = 0.1653，新损失约 0.697 < 0.7225，确实变小了。✓

</details>

## 术语卡

| 术语 | 解释 |
| --- | --- |
| 神经元（感知机） | 把输入加权求和、加偏置、再过激活函数的最小计算单元 |
| 权重 | 每个输入对神经元输出的影响力系数，训练要更新的参数 |
| 偏置 | 不依赖输入的常数项，把激活的分界线整体平移 |
| 激活函数 | 施加在加权和上的非线性函数，非线性能力的唯一来源 |
| ReLU | 线性整流单元 f(z)=max(0,z)：正数通过、负数置零，计算便宜、应用最广 |
| 前向传播 | 输入从输入层逐层算到输出层、得到预测值的过程 |
| 隐藏层 | 输入层与输出层之间的层，把原始输入变换成更有用的表示 |
| 损失函数 | 把预测与目标的差距压缩成一个标量，训练目标是压低它 |
| MSE | 均方误差，误差平方的平均；平方让大误差受更重的惩罚 |
| 梯度 | 损失对每个参数求偏导得到的向量，指向损失上升最快的方向 |
| 梯度下降 | 沿负梯度方向、以学习率为步长反复更新参数的算法 |
| 学习率 | 每步沿负梯度方向迈出的步长，过大震荡、过小太慢 |
| 线性变换 | 输出是输入的加权和（可加常数），包括拉伸、旋转、平移等，直线仍是直线 |
| 过拟合 | 模型死记训练数据、对新数据泛化差的现象 |
