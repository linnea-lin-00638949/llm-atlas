## 为什么需要它

第 1 课讲过：前向传播把输入逐层变换为输出，损失函数——一个标量（单个数值）——衡量输出与目标的差距。但只算差距不够：得知道每个参数各该为差距负多少责。反向传播负责「算账」：用链式法则把损失对每个参数的梯度一次算清；优化器负责「行动」：按梯度决定每个参数改多少。两者合起来才是完整的「学习」闭环。

这有一层直接意义：在昇腾 NPU 上用 vLLM 跑推理时，只做前向、权重只读、不做反向传播——这是推理比训练便宜的原因之一；一旦微调，反向传播与优化器的选择直接决定训练耗时与效果。只会调框架接口的话，这一课让你看得懂 loss.backward() 到底发生了什么。一句话记住：训练每步一次前向加一次反向，推理只有前向，所以任何硬件上训练都比推理慢，NPU 也不例外。

## 核心概念

先理清关系：链式法则是数学工具；反向传播是把它套到网络上的算法；梯度是它算出的结果；优化器消费梯度；参数更新是最后一步。

### 链式法则

定义：复合函数求导规则。若 L 是 y 的函数、y 是 x 的函数，则 ∂L/∂x = ∂L/∂y·∂y/∂x，多层复合逐层连乘。∂L/∂x 读作「L 对 x 的偏导数」：把其它变量当常数、只对 x 求导；L 同时依赖多个量，所以用 ∂ 而不用 d。

直觉：误差像水流过一串管道，每节被该节的「放大倍数」（局部导数）缩放一次，总效果是各节倍数之积。

机制：前向时存下每层中间值，反向时从末层起逐层相乘，每层只算自己的局部导数。

### 反向传播

定义：在前向计算图上，从损失出发、沿与计算相反的方向，用链式法则逐层求出每个参数梯度的算法。

直觉：传话游戏倒着玩——最后一人知道自己差多少，把「误差」按每人贡献比例逐级往回传。

机制：先做前向并缓存中间值（加权和 z、激活输出 a），再从输出端算 ∂L/∂输出，逐层乘本层局部导数（乘权重、乘激活函数导数），累加到对应参数的梯度缓存（.grad）上——同一参数被多条路径使用时各路径梯度相加，但参数值此刻不被修改。框架里 loss.backward() 做的自动微分（框架按计算图自动求导）就是这个流程。每个神经元只做两件事：算自己的局部导数，把上游误差传下去。

### 梯度

定义：损失对各参数求偏导组成的向量，指向损失上升最快的方向。

直觉：站在山上，梯度是脚下最陡的上坡方向；想下山就走它的反方向。

机制：每个分量回答「这个参数变一点点，损失变多少」。例如某分量是 3，参数加 0.01，损失约增 0.03；一次反向传播算齐全部分量。

### SGD / Momentum / Adam

定义：三种最常用的参数更新规则，统称优化器。

- SGD（随机梯度下降）：θ←θ−α·g。用小批量（随机抽的一批样本）估计梯度 g，α 是学习率（步长系数）。
- Momentum：给更新加惯性。v←β·v+g，θ←θ−α·v，β 常取 0.9：一致方向加速、来回抖动被抵消。
- Adam：维护梯度的一阶矩 m 与二阶矩 v——一阶矩≈梯度的滑动平均（反映方向/趋势），二阶矩≈梯度平方的滑动平均（反映幅度/波动）：m←β₁m+(1−β₁)g，v←β₂v+(1−β₂)g²；偏置修正（除以 1−βᵗ，抵消从 0 起步的偏差）后 θ←θ−α·m̂/(√v̂+ε)，ε 防除零，默认 10⁻⁸。

直觉：SGD 是每次按当前地形迈固定一步；Momentum 是滚下山的小球；Adam 给每个参数配「自动档」：梯度大就缩小步长、梯度小就放大步长。

机制：Adam 的 m̂/√v̂ 把梯度按自身历史幅度归一化；当梯度幅度大致稳定时 m̂/√v̂≈1，每个参数的更新幅度被约束在 α 的量级——这正是它相比 SGD 的改进：每参数自适应步长、对梯度尺度不敏感。

### 参数更新

定义：把优化器算出的更新量写回参数：θ←θ+Δθ。

直觉：下完一盘棋，按复盘结论调整策略权重。

机制：每批数据重复一轮：前向 → 算损失 → 反向求梯度 → 优化器算 Δθ → 更新参数。「训练」就是这五步循环几十万次。

## 一步一步理解

两层网络：输入 x=1，目标 y=0；隐层一个神经元 z₁=w₁x+b₁，激活 ReLU（输出 max(0,z)）；输出层线性 ŷ=w₂a₁+b₂；损失 L=½(ŷ−y)²。初始 w₁=2，b₁=−1，w₂=1，b₂=0。

前向：z₁=2×1−1=1；a₁=ReLU(1)=1；ŷ=1；L=½(1−0)²=0.5。

反向（从右往左，每步是链式法则的一环）：
1. ∂L/∂ŷ = ŷ−y = 1
2. ∂L/∂w₂ = ∂L/∂ŷ·∂ŷ/∂w₂ = 1×a₁ = 1；∂L/∂b₂ = 1
3. ∂L/∂a₁ = ∂L/∂ŷ·∂ŷ/∂a₁ = 1×w₂ = 1
4. ∂L/∂z₁ = ∂L/∂a₁·ReLU′(z₁) = 1（z₁>0）
5. ∂L/∂w₁ = ∂L/∂z₁·∂z₁/∂w₁ = 1×x = 1；∂L/∂b₁ = 1

反向数据流（每个分叉点分出对应分支）：

```
L → ∂L/∂ŷ ─┬─ ×a₁ ───────────→ ∂L/∂w₂
           ├─ ×1 ────────────→ ∂L/∂b₂
           └─ ×w₂ → ∂L/∂a₁ ─ ×ReLU′ → ∂L/∂z₁ ─┬─ ×x → ∂L/∂w₁
                                               └─ ×1 → ∂L/∂b₁
```

SGD 更新，α=0.1：w₁=1.9，b₁=−1.1，w₂=0.9，b₂=−0.1。再前向验证：z₁=0.8，a₁=0.8，ŷ=0.9×0.8−0.1=0.62，L≈0.19<0.5，损失确实变小。

换 Adam 更新 w₂（g=1，β₁=0.9，β₂=0.999，第一步 t=1）：m=0.1，v=0.001；修正后 m̂=0.1/(1−0.9)=1，v̂=0.001/(1−0.999)=1；更新量=−0.1×1/(1+10⁻⁸)≈−0.1。若某参数梯度为 0.01，第一步的 m̂/√v̂ 仍是 1，更新仍≈0.1——这就是「对梯度尺度不敏感」的来源。该性质只在梯度幅度大致稳定时成立：若相邻两步梯度从 100 骤降到 0.01，第二步 m̂/√v̂≈0.67，更新会明显小于 α。

## 常见误区

1. 「反向传播会自动找最优参数。」错：它只做一次精确的「按贡献记账」，算出当前位置的梯度；往哪走、走多远由优化器决定，能否到达最优解由整个训练过程决定。
2. 「梯度为 0 就说明训练好了。」错：可能停在鞍点（梯度为零但不是最低点的位置）或平坦区，也可能是 ReLU 死区（z₁≤0 时 ReLU′=0，该神经元从此收不到梯度）。要看损失曲线与验证集指标。
3. 「Adam 一定比 SGD 好。」错：Adam 收敛通常更快、对学习率相对不敏感（仍需选择，常以 1e-3 起步，微调时更小），但带 Momentum 的 SGD 在部分任务上泛化（在新数据上的表现）更好。没有绝对最优。
4. 「优化器配置越花哨越好。」错：多数任务用 SGD 或 Adam 的默认超参（需人预先设置的量，如学习率）、配一个合适的学习率就能跑通；先跑通基线，再谈调参。

## 一句话总结

反向传播 = 链式法则在计算图上的反向应用，一次算出全部参数的梯度；优化器决定怎么用梯度更新参数——先有梯度，才有更新。

## 自测题

### 1. 反向传播和链式法则是什么关系？为什么一次反向能算完所有参数的梯度？

<details><summary>查看答案</summary>反向传播就是把链式法则套到前向计算图上：从损失出发，沿计算反方向逐层乘局部导数。每个参数的梯度对应图上路径的连乘，中间量（如 ∂L/∂a₁）可被多条路径复用，所以一次反向就能算完全部参数的梯度。</details>

### 2. 画出本课两层网络的反向数据流：∂L/∂ŷ 与 ∂L/∂z₁ 各分出哪些分支？

<details><summary>查看答案</summary>L → ∂L/∂ŷ，在此分叉：×a₁→∂L/∂w₂、×1→∂L/∂b₂，主干继续 ×w₂→∂L/∂a₁→×ReLU′→∂L/∂z₁；∂L/∂z₁ 再分叉：×x→∂L/∂w₁、×1→∂L/∂b₁。规律：权重梯度乘该连接的输入（∂ŷ/∂w₂=a₁，∂z₁/∂w₁=x），偏置梯度乘 1（∂ŷ/∂b₂=∂z₁/∂b₁=1）。</details>

### 3. SGD、Momentum、Adam 的更新公式各是什么？Adam 相比 SGD 改进了什么？

<details><summary>查看答案</summary>SGD：θ←θ−α·g，只用当前梯度。Momentum：v←β·v+g，θ←θ−α·v，用历史梯度滑动平均加惯性，一致方向加速、抖动抵消。Adam：m←β₁m+(1−β₁)g，v←β₂v+(1−β₂)g²，偏置修正后 θ←θ−α·m̂/(√v̂+ε)。改进：m̂/√v̂ 按梯度自身历史幅度归一化，梯度大小不同仍得到幅度相近（α 量级）的更新——每参数自适应步长、对梯度尺度不敏感。</details>

### 4. 梯度分量为 0，能说明训练完成吗？举两个反例。

<details><summary>查看答案</summary>不能。反例一：鞍点——梯度为零但不是最低点的位置，沿某个方向损失还能继续下降。反例二：ReLU 死区——z≤0 时 ReLU′=0，该神经元从此收不到梯度、不再更新，但整个网络未必训练好。判断依据是损失曲线与验证集指标，而非单点梯度是否为零。</details>

### 5. 「反向传播会修改参数」错在哪？完整的一步训练是哪五步？

<details><summary>查看答案</summary>反向传播只把各路径的梯度累加写入参数的梯度缓存（.grad），参数值此刻不被修改；真正改参数的是优化器：算出更新量 Δθ 后执行 θ←θ+Δθ。完整一步：前向 → 算损失 → 反向求梯度 → 优化器算 Δθ → 更新参数。</details>

## 术语卡

| 术语 | 解释 |
| --- | --- |
| 前向传播 | 输入逐层加权求和与激活变换得到输出、进而算出损失 |
| 损失函数 | 衡量输出与目标差距的标量函数，训练目标是让它变小 |
| 链式法则 | 复合函数求导规则：外层导数乘内层导数，多层连乘 |
| 梯度 | 损失对各参数偏导组成的向量，指向上升最快的方向 |
| 反向传播 | 沿计算图反向用链式法则逐层求每个参数梯度的算法 |
| 学习率 | 更新步长系数 α：太大震荡、太小收敛慢 |
| SGD | 随机梯度下降：用小批量样本估计梯度，θ←θ−α·g |
| Momentum | 更新加惯性（历史梯度滑动平均），一致方向加速 |
| Adam | 按梯度一阶矩/二阶矩归一化，每参数各有自适应步长 |
| 参数更新 | 执行 θ←θ+Δθ 的步骤，是「学习」的实际落点 |
