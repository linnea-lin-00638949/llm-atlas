# 第 21 课 · 数据工程：从原始网页到能训的 token

> 学完今天，你能：
> 1. 走完「正文抽取 → 语言识别 → 去重 → 质量过滤 → 去污染」五道工序，说清每道的判断信号，以及误杀、漏放怎么回到 loss 曲线。
> 2. 手算 1−(1−s^r)^b 与阈值 s≈(1/b)^{1/r}，解释为什么精确去重删不掉模板站、必须做段落级。
> 3. 设计 SFT/偏好数据的配比与合成流水线，说清教育分类器的偏置、epoch 衰减与 model collapse 的触发条件。

## 课前自测

1. 上一课说 DPO 的上限由偏好数据的「覆盖」决定——具体是什么的覆盖？如果 rejected 只来自一个模型，缺口在哪？
2. 同一份语料重复 3 个 epoch，和 3 倍大的不重复语料，效果一样吗？
3. 去重为什么既提升效果、又降低训练成本？这两件事是同一个机制吗？
4. 用商用模型生成 100 万条指令数据，签的条款里最该确认哪一句？
5. 训练集混进了评测集的原题，你会在指标曲线上看到什么？

## 为什么需要它

上一课的 DPO 收在「离线偏好对的覆盖」上。覆盖不是感觉，是工序：正文怎么抠、重复怎么删、低质怎么筛、配比怎么调、合成数据能不能补长尾。

先记总账（本课设定值，非实测）：一条 edu 管线从原始 HTML 到能训 token，保留率约 2%，即 1 亿好 token 背后约 50 亿原始 token。注意 2% 是「原始 : 成品」的存留比，不是边际成本——成品翻倍只需原始页面翻倍。可公开核对的锚点只有 FineWeb 15T → FineWeb-Edu 1.3T（约 9%）。

## 核心概念

### 一、五道工序，八个步骤，每道报两个数

**定义**：管线 = 正文抽取 → 语言识别 → 去重 → 质量过滤 → 去污染。这是五道的概念划分；worked example 拆成 8 步（去重拆精确/近似/段落，质量过滤拆启发式/分类器），两种口径是同一件事。

**直觉**：像淘金，淘掉的是特定形状的沙子，留下的金子里也混着特定形状的杂质。所以每道报两个数：保留率、偏置。

**机制**：顺序按成本排，贵的放后面：抽取 → 语言 → 启发式 → 精确去重 → MinHash → 段落级 → 分类器 → 去污染。先删一半再上 GPU，账单直接减半；NPU（昇腾这类加速卡）上跑分类器必须批量推理，一页一页喂会把卡喂成空转。

| 工序 | 判断信号 | 本课保留率 | 主要偏置 |
| --- | --- | --- | --- |
| 正文抽取 | DOM 树 + 启发式（trafilatura） | 92% | 误杀表格/JS 正文；漏掉模板文字 |
| 语言识别 | fastText lid.176 top-1 ≥ 0.65 | 约 55% | 误杀短文本与混排页 |
| 去重 | SHA-256 / MinHash-LSH / 后缀数组 | 约 54% | 代表文档的选择偏置 |
| 质量过滤 | 启发式 70%（去重前）+ 分类器 9%（去重后） | 约 6% | 压低代码、公式、低资源语言 |
| 去污染 | benchmark n-gram 索引 | 99.5% | 删不干净，也误删正常文本 |

取舍：trafilatura 走 DOM 树 + 启发式，约 20 ms/页，能剥导航页脚，但结构不规整会失败；正则快，分不清正文与模板，模板文字一路流到后面，被「长度够、符号比例正常」判成合格。语言阈值调低多留数据、引入错标，调高误杀短文本。启发式便宜可解释，只挡明显垃圾。

### 二、去重的三种粒度

**定义**：文档级精确（规整化后全同）、文档级近似（Jaccard 超阈值）、段落级（文档内或语料内的重复片段）。

**直觉**：三种重复对应三种病——镜像站与转载、换标题重发、每篇都带的导航栏与免责声明。前两种删文档，第三种删 token。

**机制**：
- 精确哈希：规整化后算 SHA-256，同哈希即重复，O(N) 最便宜，抓不住模板站。
- MinHash + LSH：切 5-gram 词片（连续 5 个词，词级，不是 5 个 token），k 个哈希函数取最小值成签名，签名重合率近似 Jaccard；切成 b 个 band、每 band r 行，任一 band 全同即进候选，再精确算 Jaccard；候选对用并查集（union-find）并成簇，每簇留一篇代表——留最长还是留最高分，本身就是偏置。
- 段落级：全语料拼串建后缀数组，或段落哈希近似；代价是 n 字节约 4n 字节，1000 亿字符要 400 GB，必须分片。

**收益**：重复文档让容量花在背诵上，重复样本在梯度里被放大，等于偷改配比；删 30% token 就省 30% 算力。但这不是同一机制：效果走梯度，成本走 token 数，共同前提只是重复 token 的边际信息量低。

阈值 t≈(1/b)^{1/r}。b=16、r=8 时 t≈0.71；s=0.9 的对命中 0.9999，s=0.5 只有 6%——一条陡峭的 S 曲线。b 调大曲线左移（召回高、候选多），r 调大更陡。换分词或 tokenizer 会改变重复判定，阈值要跟着口径走。

### 三、质量分类器：FineWeb-Edu 的 0–5 分

**定义**：小模型给网页打「教育价值」0–5 分，只留高分。

**直觉**：没法给 100 亿网页雇人打分，就让强模型标 46 万篇，小模型学会它的口味去标全量——一次昂贵标注换全量廉价推断。

**机制**：Llama-3-70B-Instruct 标 46 万条（41 万训 + 5 万验证）→ 在 Snowflake-arctic-embed-m 句向量上接线性回归头 → 全量推断、取整到 0–5 → 只留 ≥3。FineWeb 15T 过完这刀剩 1.3T（约 9%），即 FineWeb-Edu。

**例子**：同参数、同 token、同配方，FineWeb-Edu 在 MMLU、ARC 上明显高于 FineWeb——「像教科书」与「考得好」相关，但相关不是相等。

### 四、数据配比与课程学习

**定义**：w = (网页, 代码, 数学, 多语, 书籍) 的 token 权重向量，不是一堆固定文件。

**直觉**：能力分布 ≈ 配比 × 每 token 学习效率。代码多则推理与结构化输出强、文风硬；网页少则知识面窄。

**机制**：Llama 3 约 50% 通用 / 25% 数学推理 / 17% 代码 / 8% 多语（以原文为准）。配比靠小规模消融：固定总 token、只动一格、看目标 benchmark。重复 epoch 会衰减——「数据受限 + 固定算力」下重复到约 4 个 epoch 的 loss 与唯一数据几乎无差，再多则收益趋零（Muennighoff 等）。课程学习在预训练里收益有限（token 太多、梯度噪声把顺序效应平均掉），SFT 数据少、每步影响大，排序更容易看出差别——经验结论，别当定律。

### 五、合成数据与许可

**定义**：self-instruct：种子指令 → 模型生成新指令 → 过滤 → 生成回答 → 再过滤 → 入池。

**直觉**：用钱换长尾，补真实数据里稀缺的格式与语言。

**机制**：有用的三种：补长尾格式（JSON schema、工具调用）、补推理链（强模型蒸馏）、补低资源语言。有害的：反复用自己或同族模型的输出训练自己，分布收窄——先丢长尾（early collapse）再整体退化（late collapse），即 model collapse；有真实数据锚定、或累积历代数据而非替换，可以不塌。工程上两条硬约束：商用条款常把「用输出训练其他模型」单独限制，别拿宣传页当合同；数据血缘要能回答「这条 token 来自哪个 URL、哪个快照（snapshot，某次抓取的时间切片）、过了哪些过滤」，否则一条删除请求只能重训。

## 一步一步理解

设定：1,000 万条原始 HTML，平均每页 800 token 正文，目标英文。

1. 正文抽取：成功率 92% → 1e7×0.92×800 = 73.6 亿 token。换正则每页多留约 1,000 token 模板文字，其中约三成是导航页脚。
2. 语言识别：英文占 60%，阈值 0.65 再砍 8% 短文本/混排 → 73.6×0.60×0.92 = 40.6 亿。
3. 启发式：留 70% → 28.4 亿。
4. 精确哈希：删 10% → 25.6 亿。
5. MinHash：k=128、b=16、r=8，阈值 ≈0.71；0.9 的对命中 0.9999，0.5 的只有 6%。这刀删 25% → 19.2 亿。
6. 段落级：每篇平均删 20% → 15.4 亿。
7. 分类器：≥3 留 9% → 1.39 亿。
8. 去污染：再删 0.5% → 约 1.38 亿。

总账：1.38/73.6 ≈ 1.9%。从 73.6 亿到上分类器前的 15.4 亿，中间五步（语言/启发式/精确/近似/段落）合计只剩 21%；分类器再砍 91%。成品翻倍 ≈ 原始页面翻倍（约多抓 50 亿 token 的页面）；2% 是原始/成品比，不是边际成本。想非线性提升，只能动阈值、去重、配比这些系数本身。

9. 配比：预算 10T，按 50/25/17/8 → 5T / 2.5T / 1.7T / 0.8T。代码 17%→25%、网页 50%→42%：代码 +0.8T、网页 −0.8T。
10. epoch 账：只有 3T 唯一 token，跑 5 个 epoch 凑 15T。按教学折扣 1.0/1.0/1.0/0.95/0.6：有效数据 3T×4.55 ≈ 13.7T，不是 15T。折扣表是教学虚构（刻意与「前 4 个 epoch 近似新数据」对齐），不是论文拟合值。

## 常见误区

**一、「分类器分数 = 数据质量」。** 分数是代理指标的读数，由标注者（一个商用大模型）的口味定义。它会系统性误杀代码、公式密集页、低资源语言、口语化但有用的对话，也会留下「像教材但空洞」的 SEO 长文。正确用法：当筛子不当尺子——留 85–90% 高分 + 10–15% 未过滤语料作反同质化配额，代码/数学/多语单独抽样人评。

**二、「去重越彻底越好」。** 段落级去重会删掉代码里的重复行、法务模板、公式表；MinHash 阈值设到 0.5 会把同主题的不同文章并成一簇。按语料类型分阈值：网页 0.7 上下，代码基本只做精确去重。删前抽检被删的 200 篇。

**三、「配比抄 50/25/17/8 就行」。** 配比与 tokenizer、清洗口径、目标 benchmark 强耦合，百分比的分母是「过滤后的 token」，换一版过滤器，同样的百分比含义就变了。

**四、「合成数据是免费的」。** 没有真实锚定时，反复用自己的输出训练会先丢长尾再整体退化；且「生成得多」不等于「补得上」——合成数据几乎不带来新信息，只改变已有信息的分布。

### 回收课前 5 问

1. 覆盖的是偏好对在「回答空间」上的分布；rejected 只来自一个模型，缺口是它自己不会犯的那类错。
2. 不一样：3 epoch 是同一批 token 重复，前 4 个 epoch 内接近新数据，但边际收益递减；3 倍新数据带来 3 倍唯一信息。
3. 不是同一机制：效果走梯度（重复样本被放大、挤占容量），成本走 token 数。
4. 最该确认「能否用输出训练其他模型」那一句，以及商用与再分发范围；宣传页不是合同。
5. 指标会异常高、训练早期就高，与 loss 脱钩，换个题面就掉——去污染就是拆这个。

## 一句话总结

一个 token 要过五道工序，每道都带偏置：去重删的是容量浪费与算力，分类器删的是「不像教材」的长尾，配比是决定能力分布的权重向量，合成数据只有在真实数据锚定时才是增量。核心不是「多」，而是每个过滤决定都能报出「删了多少、留下什么偏置」。

## 自测题

### 1. 保留率复算

2000 万页原始 HTML，抽取成功率 90%，语言过滤后留 60%，分类器留 8%，平均 800 token/页。最终多少 token？若目标是 1 亿 token，要抓多少页？

<details><summary>查看答案</summary>

2000 万 × 0.9 × 0.6 × 0.08 = 86.4 万页；×800 = 6.9 亿 token。要 1 亿 token 则需 1e8 ÷ (800×0.9×0.6×0.08) ≈ 289 万页。这是纯乘法：任一环节保留率减半，最终产出也减半，所以改系数比加带宽更划算。

</details>

### 2. MinHash 命中率

b=16、r=8，s=0.8 的文档对进候选的概率是多少？为什么它高于阈值 0.71，却只有约 95%？

<details><summary>查看答案</summary>

0.8^8 = 0.1678；1−(1−0.1678)^16 = 1−0.8322^16 ≈ 0.947。阈值 (1/b)^{1/r} 只是 S 曲线中点附近（P≈0.5）的点，0.8 离 0.71 不够远；要提召回就降 b 或减 r，代价是候选对与比较成本上升。

</details>

### 3. 3 epoch vs 3 倍新数据

同一份 1T 语料跑 3 个 epoch，与 3T 不重复语料，在固定算力下效果一样吗？

<details><summary>查看答案</summary>

不一样。Muennighoff 等的结论是「数据受限 + 固定算力预算」下重复到约 4 个 epoch 的 loss 与唯一数据几乎无差，不是「重复 3 遍 = 3 倍数据」。3T 唯一 token 提供 3 倍信息；1T 重复 3 遍仍只有 1T 的信息，且第 2、3 遍边际收益已在下降。超出 4 个 epoch 后，新增算力的收益趋近于零。

</details>

### 4. 阈值公式与 b/r 取舍

写出 MinHash 的阈值近似式，并说明把 b 从 16 提到 64、r 不变时，召回、候选数与成本各怎么变。

<details><summary>查看答案</summary>

t ≈ (1/b)^{1/r}。b 增大 → t 变小，曲线左移，同样的 s 更容易进候选，召回上升；但每个文档要进更多桶，候选对与精确算 Jaccard 的成本都上升。r 增大则曲线更陡、对 s 更敏感。b·r = k 是签名长度，k 越大估计越准、成本越高。

</details>

### 5. 合成数据什么时候塌

用模型 A 生成数据训模型 B，再把 B 的输出拿去训 C，一定塌缩吗？什么条件下不塌？

<details><summary>查看答案</summary>

不一定。塌缩的条件是「无真实数据锚定 + 逐代替换」：每一代只用上一代合成数据，分布逐代收窄，先丢长尾（early collapse）再整体退化（late collapse）。不塌的条件：混入真实数据、或累积历代真实+合成数据而不是替换（arXiv:2404.01413）；任务越窄、验证信号越强，退化越慢。工程上还要先确认许可允许「用输出训练其他模型」。

</details>

| 术语 | 解释 |
| --- | --- |
| 数据管线 | 抽取→语言识别→去重→质量过滤→去污染 的串联；每道报保留率与被删样本抽检结果。 |
| 正文抽取 | 从网页源码剥出正文、去掉导航页脚评论。 |

| 精确哈希去重 | 规整化全文算 SHA-256，同哈希即重复；O(N) 最便宜，抓不住模板站。 |
| Jaccard 相似度 | 两集合交集除以并集，度量 5-gram 词片的重合度。 |
| MinHash | k 个哈希函数对词片集合取最小值成签名，签名重合率近似 Jaccard。 |
| LSH / band | 签名切 b 个 band、每 band r 行，任一 band 全同进候选；把 O(N²) 降到近线性，t≈(1/b)^{1/r}。 |
| 并查集 | union-find：把互为重复的候选对合并成簇；每簇留一篇代表，代表选择本身是偏置。 |
| 段落级去重 | 删文档内或语料内的重复片段，专治导航栏、免责声明、SEO 套话。 |
| 后缀数组 | 所有后缀按字典序排好的数组，用来找重复子串；n 字节约 4n 字节。 |
| 启发式规则 | 词数、平均词长、符号比例、重复 n-gram 占比；便宜可解释，但压低公式、代码、诗歌。 |
| 质量分类器 | 小模型打分只留高分；FineWeb-Edu 打 0–5 教育价值，阈值 ≥3，留约 9%。 |
| 代理指标 | 近似真实目标的可计算量；「像教科书」近似「下游能力」，相关但不相等。 |
| 去污染 | 用 benchmark 题面做 n-gram 索引（GPT-3 用 13-gram），删命中样本，防指标虚高。 |
| 数据配比 | 各领域 token 占总预算的比例，是一组可调权重向量。 |
| epoch 衰减 | 重复 token 的边际价值随 epoch 下降；约 4 个 epoch 内接近新数据。 |
| 课程学习 | 按难度排序喂数据；预训练里收益有限，SFT 里更明显。 |
| self-instruct | 种子指令 → 生成指令与回答 → 过滤入池的合成数据流水线。 |
| 模型坍缩 | 反复用自己的输出训练导致分布收窄：长尾先丢、再整体退化；有真实锚定可不塌。 |
| NPU 批量推理 | 在昇腾这类加速卡上把样本攒批再送模型；逐条送会因启动开销把卡喂成空转。 |
| 快照 | snapshot：某次抓取的时间切片，是数据血缘与可追溯删除的定位单位。 |
| 数据血缘 | 记录每条数据的来源 URL、快照与过滤轨迹，使删除请求可定位、可追溯。 |
